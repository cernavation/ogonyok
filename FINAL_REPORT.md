## 5. Инструкция для новичка: Запуск и деплой с нуля

### Шаг 1. Локальный запуск в демо-режиме
```bash
# 1. Клонировать ветку
git checkout night-shift

# 2. Установить зависимости и браузерные движки
npm install
npx playwright install chromium webkit firefox

# 3. Запустить проект в демо-режиме
npm run dev
# Открыть в браузере: http://localhost:3000
```

### Шаг 2. Подключение живого бэкенда Supabase
```bash
# Запусти интерактивный терминальный мастер (он спросит URL и ключи):
npm run setup
```
Мастер автоматически:
1. Проверит валидность ключей через API.
2. Сохранит `.env.local`.
3. Накатит полную SQL-схему со всеми RLS-политиками.
4. Создаст бакеты для аватаров и медиафайлов.

### Шаг 3. Настройка входа через Google
```bash
# Запусти помощник по Google OAuth:
npm run check-google
```
Скрипт выведет точные ссылки и Redirect URIs для Google Cloud Console и панели Supabase:
- `Authorized redirect URI`: `https://<YOUR-PROJECT-REF>.supabase.co/auth/v1/callback`

### Шаг 4. Проверка живого сервера
```bash
# Запусти сквозной тест бэкенда:
npm run verify-live
```
Убедись в зелёном выводе: `RLS: ✅ | Realtime: ✅ (<120ms) | Storage: ✅ | Очистка: ✅`.

### Шаг 5. Деплой на Vercel
```bash
# 1. Запусти проверку перед деплоем:
npm run predeploy

# 2. Деплой через Vercel CLI:
vercel --prod
```
Подробная пошаговая инструкция с картинками находится в файле [`ИНСТРУКЦИЯ_VERCEL.md`](file:///Users/user/Desktop/ogonyok-ai-clone/ИНСТРУКЦИЯ_VERCEL.md).
