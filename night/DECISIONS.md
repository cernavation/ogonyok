# ПРИНЯТЫЕ РЕШЕНИЯ (DECISIONS)

- **ИИ-оценка**: основной провайдер Gemini (модель из env GEMINI_MODEL), при ошибке или лимите автоматический фолбэк на DeepSeek. Один серверный модуль lib/server/ai.ts, UI не знает о провайдере и не пишет «Gemini» в тостах, пишет «ИИ».
- **Каноническая модель дневника**: `days` + `prides` + `gratitudes`. Для совместимости создать VIEW `diary_days`. Таблицы `entries` и вся «схема V2» признаются устаревшими.
- **Приглашение /invite/[username]**: сначала брендированная карточка пригласившего (аватар, стрик, «Присоединиться»), затем регистрация, затем автоматическая заявка в соратники.
- **RLS включён везде**, allow_all_dev удалён навсегда. Демо-режим без входа работает только на localStorage.
- **Звонки**: оставить текущий WebRTC + Supabase Realtime signaling, добавить TURN через Metered.ca (ключи в env, выдача через /api/webrtc/ice-servers с проверкой авторизации).
- **Тарифы**: free | pro | ultra. Значение `premium` в базе мигрируется в `pro`. Тариф меняется ТОЛЬКО ролью service_role (админ-скрипт, SQL Editor, вебхук оплаты). Клиент, даже авторизованный, изменить тариф не может.
- **Rate-limit и квоты** хранятся в Postgres (RPC), а не в памяти лямбды.
- **Терминология в UI**: «Соратники» везде (убрать смесь «Друзья/Круг соратников/Подписки», где это один и тот же смысл). «Подписки» остаются отдельной односторонней концепцией.
