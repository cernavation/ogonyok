# Независимый аудит «Огонёк» — Волна 2 (`AUDIT_02`)

- **Дата аудита**: 2026-11-15
- **Роль**: Независимый внешний аудитор (без предвзятости, цель — выявление дефектов)
- **Окружение**: локальный сервер Next.js 16.4.0 (`http://localhost:3000`), Supabase PostgreSQL
- **Тестируемые аккаунты**: `audit_free` (Free), `audit_pro` (Pro), `audit_ultra` (Ultra)
- **Тестируемые вьюпорты**: `1210×756` (основной экран владельца, десктоп) и `390×844` (мобильный)
- **Методология**:
  1. Полный сквозной интерактивный обход живым пользователем всех экранов и модалок через Playwright.
  2. Стресс-тестирование и хаос-сценарии: быстрые двойные/тройные клики, потеря сети mid-action, экстремально длинные строки без пробелов (800+ симв.), RTL-текст (арабский), комбинированные эмодзи, списки из 0 и 1000 элементов.
  3. Проверка на соответствие 11 правилам `CONTRACT.md` и данным `review/guard-report.md`.
  4. Фиксация скриншотов на каждом шаге в директорию `review/audit-02/`.
