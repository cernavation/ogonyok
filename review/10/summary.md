# Итоги шага 10: Надёжность WebRTC звонков, TURN Metered и режим PiP

**Что сделано**:
- Временные TURN credentials от Metered через защищённый API `/api/webrtc/ice-servers` (только для авторизованных) с режимом `relay-only`.
- ICE restart при смене сети (Wi-Fi ↔ LTE) и разрывах связи, таймаут 45 с = `missed` («Абонент не отвечает (45 с)»).
- 6 канонических статусов звонка (`ringing`, `connected`, `ended`, `rejected`, `missed`, `busy`), входящий вызов поверх любого экрана с мелодией и кнопками.
- Блокировка: звонок заблокированному пользователю не инициируется (`busy`), видеозвонок разрешён по тарифу (Pro/Ultra, Free только аудио).
- Плавающее мини-окно PiP (`#call-pip-window`) для свободной навигации по приложению («Поиск», «Лента», профиль) без разрыва связи.
- Понятные ошибки доступа к микрофону/камере; история звонков в чате как системные строки через RPC `record_call_result`.
**Что проверено**:
- Playwright E2E с fake-media: аудио, видео, отказ, 45с таймаут, занято/блок, PiP; `iceConnectionState=connected` и ненулевые байты getStats (3393 байт).
- 545/545 тестов `node:test` PASS, TypeScript 0 ошибок, замеры бюджета в `review/10/budget.md` и чек-лист в `review/10/manual_check.md`.
- 5 скриншотов в `review/10/`: `audio_call_connected`, `video_call_pip`, `call_rejected`, `call_missed`, `call_busy_blocked`.
**Что не делалось**: внешний вид окна звонка строго сохранён, 0 изменений дизайн-токенов, 10 пунктов левого меню, слово «Соратники» отсутствует.
