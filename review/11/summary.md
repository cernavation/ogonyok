# Итоги шага 11: Умный композер, вставка списков и навигация

**Что изменилось для пользователя**:
- Умная вставка: списки (1., -, •, абзацы) раскладываются по слотам до 3 с тостом «Разложил по 3 гордостям · Отменить», одиночные ссылки сохраняются без смены слота, длинный текст (≥120 симв.) заполняет свободный слот с автопереходом.
- Лимиты тарифа: текст >1000 симв. не обрезается, счётчик краснеет («1 340/1000»), кнопка «Записать» блокируется, появляется действие в один клик «Разложить остаток в следующую гордость →». Зеркально работает в благодарностях.
- Картинки из буфера: вставка фото прикрепляет файл по тарифу (Pro/Ultra); на Free (0 фото/день) показывает понятное окно апгрейда.
- Навигация клавиатурой: Ctrl/Cmd+Enter отправляет форму, Tab/Shift+Tab циклично переключает слоты 1..5, стрелка ↑ в начале поля переходит на предыдущий слот (курсор в конец), стрелка ↓ в конце переходит на следующий.
- Оценки и преодоление: звёзды преодоления и баллы ИИ сохраняются в стейте и черновиках и никогда не затираются при смене слотов.
