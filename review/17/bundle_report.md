## 2. Разделение кода по маршрутам (Route Splitting)

- **Главная (`/`)**: 39 статических и серверных маршрутов скомпилированы за 4.4с.
- **Статические страницы**: `/_not-found`, `/chats`, `/premium`, `/privacy`, `/terms` сгенерированы как SSG (○).
- **Динамические API эндпоинты**: `/api/*` изолированы и выполняются исключительно на сервере (ƒ), не утяжеляя клиентский бандл.
- **Service Worker (`public/sw.js`)**: размер 3.2 KB, строгая политика исключения кэширования API и WebSocket.
