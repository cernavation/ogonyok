# 🔥 Огонёк — CRM твоей жизни

> Веб-приложение личной летописи гордостей и благодарностей в формате премиальной социальной сети (уровень Threads / Instagram / Linear).
> Философия: человек фиксирует победы каждый день, а через 700 дней может открыть любой день за 2+ года и увидеть свои победы того дня.

---

## ⚡ Быстрый старт в 3 команды

```bash
# 1. Установка зависимостей
npm install

# 2. Проверка и настройка окружения
npm run check-setup

# 3. Запуск приложения
npm run dev
```

Приложение доступно по адресу: **[http://localhost:3000](http://localhost:3000)**

---

## 🛠 Стек технологий

- **Фронтенд:** Next.js 15 (App Router), React 19, TypeScript, Tailwind CSS, Lucide Icons, Framer Motion.
- **Бэкенд & База данных:** Supabase (Auth, PostgreSQL, Row Level Security, Realtime, Storage).
- **ИИ-ментор:** Google Gemini 2.5 Flash (`/api/ai/evaluate` + калиброванная эвристика преодоления).
- **Мессенджер:** Telegram Web UX (папки, эмодзи, цитирование, пересылка побед, реакции, статусы доставки).
- **Интеграции:** Telegram Bot API (напоминания о незакрытых днях 1–3 раза в день).
- **Деплой:** Vercel (Edge Functions, Serverless, SSR/ISR).

## 🌟 Ключевые возможности

1. **Правила летописи (PRODUCT_SPEC.md):**
   - Уровень сложности: 1, 2, 3, 4 или 5 гордостей и благодарностей в день (Правило 1).
   - Смена уровня заблокирована на 30 дней после выбора (Правило 2).
   - Огонёк **НИКОГДА** не сгорает при пропуске: стрик равен общему количеству закрытых дней (Правило 3).
   - Пропуск дней не ломает нумерацию: следующая запись попадает в следующий номер по порядку (Правило 4).
   - Закрытый день нельзя редактировать, только дополнять с отметкой «Дописано позже» (Правило 5).
   - Персональный дедлайн закрытия дня до 03:00 ночи (Правило 6).

2. **Социальная сеть & Мессенджер:**
   - Полноценный мессенджер с UX Telegram Web: папки («Все», «Личные», «Группы», «Непрочитанные»), цитирование, реакции эмодзи, пересылка побед.
   - Сторис дня с огненным акцентным градиентом.
   - Хаб исследования: поиск участников сообщества и подписки.

3. **Серверные Рейтинги:**
   - Лидерборд с серверным расчётом (SQL view + индексы в `supabase/schema.sql`).
   - Фильтры: «Неделя», «Месяц», «Всё время».
   - Вкладки: «Друзья» и «Все».
   - Закреплённая строка текущего пользователя.

4. **Глубокая Аналитика:**
   - Стрик в днях летописи.
   - График записей и средних оценок (`DynamicsChart`).
   - Карточка «Лучшая неделя» (рекорд стабильности и силы).
   - Карточка «Сравнение месяцев» (текущий vs прошлый месяц).
   - Категории «Самые частые темы» (прогресс-бары: Спорт, Бизнес, Отношения, Учёба, Характер).
   - 3 ключевых вывода с кнопкой «Обновить выводы с ИИ».

5. **Производительность (PERF.md):**
   - Переход между любыми экранами **< 200 мс** (аппаратное ускорение, отсутствие искусственных задержек).
   - Бесконечная подгрузка по 20 (`IntersectionObserver`).
   - Lazy-loading тяжёлых модулей через `next/dynamic` (`DynamicsChart`, `ChatEmojiPicker`, `MediaLightbox` и др.).
   - Мемоизация компонентов (`React.memo` на `DayCard`).
   - Lighthouse Performance Score **≥ 90**.

## 🔍 Как проверять интерфейс (UI-Аудит)

В проекте настроен постоянный автоматизированный аудит интерфейса через Playwright и сквозной протокол визуальной самопроверки (Visual Loop):

- **64 целевые конфигурации:** 9 основных экранов + 7 интерактивных состояний (окно «Записать», онбординг, регистрация, сторис, чат с сообщениями, контекстное меню поста «⋯», развёрнутый «Утренний фокус»).
- **Разрешения:** Desktop (1440×900) и Mobile (390×844) + адаптивность на 1280px, 1024px (icon-only сайдбар), 768px (планшет без бокового скролла).
- **Темы:** Dark (`x-black`) и Light (`apple-light`).
- **Строгий контроль 10 категорий дефектов:**
  1. **Налезающие кнопки (Overlap)** — строго 0.
  2. **Слипшиеся кнопки** — зазор $\ge 8\text{px}$.
  3. **Обрезанный текст** — скрытый текст без `text-overflow: ellipsis`.
  4. **Мелкий шрифт** — кегль текста $\ge 13\text{px}$.
  5. **Низкий контраст** — контрастность текста к фону $\ge 4.5:1$ (WCAG AA).
  6. **Малые зоны нажатия** — элементы $\ge 36\text{px}$ (Desktop) / $\ge 40\text{px}$ (Mobile).
  7. **Карточки в карточках** — ликвидация вложенности контейнеров.
  8. **Горизонтальный скролл** — строго 0px на всех устройствах.
  9. **Ошибки и warning'и консоли** — 0 ошибок и 0 предупреждений.
  10. **Точечный hover** — подсветка только самого элемента, никаких фоновых подсветок больших блоков.

```bash
# 1. Быстрый аудит (десктоп, тёмная тема — быстрая итерация):
npm run audit-ui:fast

# 2. Полный аудит перед сдачей (все 64 конфигурации, ожидается 0 дефектов):
npm run audit-ui

# 3. Визуальный снимок интерфейса (Visual Loop):
node scripts/vision/snap.mjs http://localhost:3000/ current-check

# 4. Проверка точечных ховеров и адаптивности:
node scripts/capture-d4-hovers.mjs
```

- Скриншоты аудита сохраняются в папку `ui-audit/`.
- Результаты замеров и дефектов: `ui-audit/BASELINE.md` (Всего дефектов: 0).
- Экспертный аудит глазами: `ui-audit/EYES.md` и `ui-audit/FINAL.md`.
- Эталонные скриншоты ховеров и контрольных ширин: `screenshots/D4/`.
