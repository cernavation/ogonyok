## 2. Честно о сотовой мобильной связи: почему обычные телефонные звонки невозможны в Web-приложении

В техническом задании упоминались звонки. Важно прояснить фундаментальное ограничение веб-стандартов:

1. **Ограничения браузерной песочницы (Web Security Sandbox)**:
   Ни один современный браузер (Chrome, Safari, Firefox, Edge) из соображений безопасности и конфиденциальности не имеет доступа к сотовому GSM/LTE/5G-модему смартфона или SIM-карте. Браузерный JavaScript физически изолирован от сотовой подсистемы операционной системы (iOS CallKit / Android TelephonyManager для инициации GSM-вызова без согласия пользователя).
2. **Как работает стандартная ссылка `tel:+1234567890`**:
   Единственное, что веб-страница может сделать — это вызвать системный диалог набора номера `tel:`, который просто переключает пользователя в стандартную звонилку телефона, где пользователь обязан сам нажать зелёную кнопку вызова. Это не автоматический звонок внутри приложения.
3. **Что требуется для настоящих телефонных звонков на сотовые номера**:
   Для звонка на обычный сотовый телефон из веб-сервиса необходим **платный облачный PSTN/SIP-шлюз** (например, Twilio Voice, Voximplant, Telnyx). Это серверный бэкенд, который тарифицируется поминутно в долларах и требует заключения операторского договора.
4. **Что сделано в «Огоньке» (золотой стандарт Web)**:
   Реализована **высококачественная WebRTC 1:1 аудио- и видеосвязь** (как в Telegram Web, Discord и Google Meet). Связь бесплатна, защищена end-to-end шифрованием (DTLS-SRTP), мгновенно соединяет пользователей прямо внутри вкладки браузера на любом устройстве (десктоп, планшет, iPhone, Android) без установки сторонних программ.

## 3. Инструкция по добавлению боевых ключей

Все интеграции снабжены элегантными fallback-режимами (в демо-режиме всё работает из коробки). Для боевого окружения добавьте в `.env.local` следующие ключи:

### 1. Google Gemini (Транскрибация аудио и Перевод)
- **Переменная:** `GEMINI_API_KEY=AIzaSy...`
- **Где получить:** Бесплатно в [Google AI Studio](https://aistudio.google.com/).
- **Назначение:** Автоматический перевод входящих/исходящих сообщений и мгновенная расшифровка голосовых сообщений на русском языке моделью `gemini-2.5-flash`.

### 2. Giphy API (GIF-анимации)
- **Переменная:** `GIPHY_API_KEY=your_api_key`
- **Где получить:** Бесплатно в [Giphy Developers](https://developers.giphy.com/).
- **Назначение:** Поиск по базе трендовых гифок в модальном окне «GIF» панели ввода.

### 3. TURN-сервер (Звонки через NAT и корпоративные файрволы)
- **Переменные:**
  - `TURN_URL=turn:turn.example.com:3478`
  - `TURN_USERNAME=user`
  - `TURN_CREDENTIAL=pass`
- **Где получить:** Бесплатный тариф [Coturn / Xirsys / Cloudflare Calls / Twilio Network Traversal](https://www.twilio.com/stun-turn).
- **Назначение:** Обеспечивает стабильное WebRTC соединение между пользователями, если они находятся за строгими симметричными NAT или мобильными операторами.

### 4. CRON_SECRET (Отложенные сообщения)
- **Переменная:** `CRON_SECRET=super_secret_cron_token`
- **Назначение:** Защита эндпоинта `/api/cron/deliver-scheduled`. Вызывается планировщиком (Vercel Cron, GitHub Actions или cron на сервере) с заголовком `Authorization: Bearer <CRON_SECRET>` каждую минуту для автоматической доставки запланированных сообщений.

## 4. Инструкция для новичка: 5-минутная ручная проверка всего функционала

1. **Запуск проекта**:
   ```bash
   npm run dev
   ```
   Откройте [http://localhost:3000](http://localhost:3000).

2. **Проверка полноэкранного мессенджера (3 колонки)**:
   - Перейдите в раздел «Чаты» в левом меню (или откройте [http://localhost:3000/chats](http://localhost:3000/chats)).
   - Убедитесь, что чат занимает **100vw × 100dvh** без лишних сайдбаров и серых полос.
   - Слева — рейка 88px с иконками, по центру — список диалогов 400px, справа — переписка до 820px.
   - Кликните на диалог «Михаил Волошин». Нажмите дважды на пузырь — появится реакция 🔥.
   - Наведите на пузырь: появятся кнопки ответа (цитирование), редакции и «⋯».
   - В поле ввода внизу введите текст: иконка микрофона сменится на оранжевую стрелку отправки.
   - Нажмите круглую кнопку «+» слева: выберите карточку победы или документ.
   - Нажмите круглую кнопку «Аудиозвонок» в шапке 72px: откроется WebRTC модалка звонка с таймером.

3. **Проверка мобильного вида (390px)**:
   - Сожмите окно браузера или включите режим мобильного устройства (F12 → iPhone).
   - Список диалогов и переписка становятся отдельными экранами с кнопкой «←».
   - Нижний таб-бар автоматически скрывается, инпут плотно прижат к низу.

4. **Проверка загрузки обложки и аватара профиля**:
   - Откройте вкладку «Профиль».
   - Наведите на обложку: в правом нижнем углу появится кнопка `[📷 Сменить обложку]`. Нажмите её.
   - В модалке выберите любую картинку: появится инструмент обрезки 3:1 с зумом и сдвигом.
   - Нажмите «Выбрать готовый градиент Огонька»: переключитесь на «Огненный рассвет» или «Пурпурный стрик». Обложка обновится моментально без перезагрузки!

5. **Проверка уровня сложности**:
   - В шапке профиля рядом со стриком найдите бейдж `[🔥🔥 Уровень 2]`.
   - Нажмите на него: откроется поповер с описанием всех 5 уровней, правилами поддержания стрика и статусом 30-дневного кулдауна.

6. **Автоматический прогон тестов одной командой**:
   ```bash
   npm run test:chat
   npm run audit-ui:fast
   ```
   Убедитесь, что все тесты горят зелёным (10/10 PASS, 0 дефектов).
