# X.COM DESIGN SYSTEM SPECIFICATION (TASTE-SKILL ENFORCED)

## 1. Typography & Hierarchy (TwitterChirp / Geist Stack)
- Display: 64px, weight 600, line-height 77px, tracking -1px
- Header LG: 24px, weight 600, line-height 29px
- Body LG (Tweet Text): 15px, weight 500, line-height 23px, tracking -0.015em
- Body MD: 14px, weight 400, line-height 20px
- Label SM (Meta, dates, stars): 12px, weight 500, line-height 16px

## 2. Shapes & Radii
- Buttons & Pills: `rounded-full` (9999px) — strict X standard for all actions and tabs.
- Cards & Inputs: `rounded-2xl` (16px - 20px) for container sheets and dialogs.
- Avatar: `rounded-full`, exactly 40x40px.

## 3. Dark Theme Tokens
- Surface: `#000000` (Pitch black background).
- Secondary Elevation: `#16181c`.
- Border Line: `#2f3336` (1px crisp dividing borders between posts).
- Text Primary: `#e7e9ea`.
- Text Muted: `#71767b`.
- Accent Blue: `#1d9bf0`.
- Accent Fire (Prides): `#ff6b35`.
- Accent Heart (Gratitudes): `#f91880`.

## 4. Components Rules
- button-primary: Black/Orange fill, text white, height 48px, rounded-full, padding 12px 24px.
- tweet-card: border-b only (#2f3336), no outer floating borders, hover:bg-white/[0.02].
- action-bar: 4 groups (Message, Fire/Retweet, Heart/Like, Share), rounded-full hover circles.
