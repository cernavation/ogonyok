# Карта тултипов интерфейса «Огонёк» (X.com Micro-Interactions)

В проекте используется кастомный компонент `<Tooltip />` поверх доступного `@base-ui/react/tooltip` со стилизацией Dark Slate X.com, задержкой показа 400ms, мгновенным скрытием при уходе курсора, закрытием по нажатию `Esc` и безопасным поведением на сенсорных экранах (`pointer: coarse`).

---
