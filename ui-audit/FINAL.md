# Финальный аудит дизайна интерфейса «Огонёк» (FINAL.md)

> **Стандарт сравнения:** X.com (Twitter Web) & Telegram Web  
> **Принципы оценки:**
> 1. **Минимализм:** Отсутствие визуального шума, избыточных рамок, карточек внутри карточек.
> 2. **Тишина:** Спокойный тёмный/светлый фон, отсутствие кричащих плашек, моргающих ховеров на всю площадь.
> 3. **Прогрессивное раскрытие:** Показ главного сразу, подробности — по клику («ещё 4 гордости» прямо в посте).
> 4. **Иконки вместо слов:** Лаконичный нижний тулбар под постом (комментарий, закладка, огонёк, поделиться, ⋯).
> 5. **Точечный hover:** Подсвечивается ТОЛЬКО сам интерактивный элемент (кнопка, иконка, строка), а не весь блок.
> 6. **Единый ритм:** Строгая вертикальная сетка с 1px разделителями (`border-b var(--border)`).
